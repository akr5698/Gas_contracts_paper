# Gas_contracts_paper  

Supplementary material to the paper: *"Contracts for Gas Prioritization to Power Plants during Winter Emergencies"*  

- **AEA_model_code_Scenario_A**: Code for the AEA model (Scenario A) presented in the paper.  
- **Baseline_model_code_Scenario_A**: Code for the Baseline model (Scenario A) presented in the paper.  
- **Appendix_to_paper**: Appendix document to the paper.  
- **List_of_data_sources**: List and links to all data sources used in the paper.
